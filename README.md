# Cuadrícula Interactiva de Coordenadas

Programa de consola en Python que representa una cuadrícula de círculos (mínimo 8×8, tamaño definido por el usuario). Todos los círculos inician vacíos `[○]`; al ingresar una coordenada (X,Y) válida, el círculo correspondiente cambia a relleno `[●]`.

## Requisitos

- Python 3.6 o superior.

## Ejecución

1. Abre `main.py` con cualquier IDE o compilador compatible con Python.
2. Ejecuta el programa.
3. Sigue las instrucciones en pantalla: define el ancho y el alto, y usa el menú para seleccionar coordenadas, ver la cuadrícula, ver el historial, reiniciar o salir.

## Recursos utilizados

Ninguno externo. Solo la librería estándar de Python.
